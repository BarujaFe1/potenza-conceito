## 🌟 Visão Geral

Conceito de interface e presença digital corporativa para Potenza — alta performance visual, tipografia refinada e engenharia de componentes.

O projeto foi construído priorizando performance, manutenibilidade de código, design system consistente e padrões modernos de engenharia de software.

---

## 🚀 Principais Funcionalidades

- **Identidade**: Identidade visual industrial e tecnológica de alto impacto
- **Showcase**: Showcase de portfólio de equipamentos e serviços industriais
- **Arquitetura**: Arquitetura modular em componentes reutilizáveis
- **Carregamento**: Carregamento progressivo de mídia e performance de ponta
- **Estrutura**: Estrutura pronta para internacionalização e expansão de catálogo

---

## 🛠️ Stack Tecnológica

O ecossistema do projeto é composto por tecnologias modernas e consolidadas:

- **Tecnologias Core**: `Next.js 15` `React 19` `Tailwind CSS` `TypeScript`
- **Estilização & UI**: Tailwind CSS, Radix UI primitives e Lucide Icons
- **Qualidade & Testes**: Linting estrito, Typecheck rigoroso e suítes automatizadas

## ⚡ Como Rodar Localmente

### Pré-requisitos
- Node.js (versão 20 LTS ou superior)
- Gerenciador de pacotes `npm`, `yarn` ou `pnpm`

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/BarujaFe1/potenza-conceito.git
cd potenza-conceito
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) (ou a porta informada no terminal) no seu navegador.

## 🧪 Qualidade de Código & Testes
